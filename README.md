# Minecraft Helper Tool

Arkadaşlar arası yarışma için hazırlanmış single-player Minecraft helper tool.

## Özellikler
- X-Ray Vision: Cevherleri blokların arkasından gösterir
- Auto-Mine: Otomatik kazma yardımcısı
- ESP: Mob ve entity takip sistemi
- Auto-Fish: Otomatik balık tutma
- GUI Menü: Güzel arayüz ile modül kontrolü

## Kurulum
```bash
pip install -r requirements.txt
python main.py
```

## Kullanım
- `F1` - Menüyü aç/kapa
- `F2` - X-Ray toggle
- `F3` - Auto-Mine toggle
- `F4` - ESP toggle
- `F5` - Auto-Fish toggle
- `F6` - Tüm modülleri kapat
- `ESC` - Programdan çık

## Not
Bu araç sadece eğitim amaçlı ve single-player kullanım içindir.
